# Bazar Dor / বাজার দর

A modern and responsive e-commerce web application designed to check and view various product prices.

## Technologies Used
- Next.js
- React
- Tailwind CSS
- DaisyUI
- Better Auth
- Git & GitHub

## Key Features
1. Fully Responsive Design across mobile, tablet, and desktop viewports.
2. Dynamic Navigation and hash-based routing with smooth scrolling.
3. Robust Product Fallback and error handling for missing items (Product Not Found).
4. Optimized Images using Next.js Image component for fast performance.
5. Accurate Sorting and filtering support for enhanced user experience.
